# 📝 我的待办清单

一个简洁、现代的待办事项 Web 应用，使用清新蓝紫渐变色调，支持优先级、编辑、筛选等功能，数据保存在浏览器本地存储中，刷新不丢失。

![待办清单](https://img.shields.io/badge/待办事项-应用-blue) ![Vite](https://img.shields.io/badge/Vite-5.4-646cff) ![Vanilla JS](https://img.shields.io/badge/Vanilla-JS-f7df1e)

---

## ✨ 功能特性

- **添加任务** — 输入任务内容，选择优先级后一键添加
- **优先级标识** — 支持高（红）、中（黄）、低（绿）三个优先级，列表自动按优先级排序
- **完成标记** — 点击复选框标记完成，已完成任务显示删除线
- **编辑任务** — 点击任务文字或编辑按钮，可修改内容和优先级（回车保存 / Esc 取消）
- **删除任务** — 单条任务可随时删除
- **筛选查看** — 在「全部 / 未完成 / 已完成」之间切换
- **任务统计** — 实时显示未完成、已完成、全部任务数量
- **清空已完成** — 一键清除所有已完成任务
- **全部清空** — 带确认弹窗，防止误删
- **空状态提示** — 列表为空时显示友好提示
- **本地存储** — 数据保存在 localStorage，刷新页面不会丢失
- **响应式设计** — 手机和桌面端均适配

## 🚀 快速开始

### 环境要求

- Node.js >= 18
- npm 或其他包管理器

### 安装与运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

开发服务器启动后，在浏览器中打开终端显示的本地地址即可使用。

## 🎨 设计亮点

- **蓝紫渐变背景** — 从浅蓝到浅紫的柔和渐变，视觉舒适
- **圆角卡片式布局** — 大圆角 + 柔和阴影，现代感十足
- **彩色优先级圆点** — 高中低三色直观区分任务重要程度
- **微交互动画** — 任务淡入、按钮缩放、卡片悬浮等细节反馈
- **自定义复选框** — 勾选动画流畅自然
- **确认弹窗** — 危险操作（全部清空）带模态确认，防止误操作

## 📦 数据存储

所有任务保存在浏览器的 `localStorage` 中（键名：`todo-app:tasks`）。

任务数据结构：

```json
{
  "id": "唯一标识",
  "text": "任务内容",
  "done": false,
  "priority": "high | medium | low"
}
```

> 数据仅存储在当前浏览器，不会上传到服务器。清除浏览器数据会导致任务丢失。
